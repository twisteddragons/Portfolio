# Intermundial
<img width="2560" height="1440" alt="image" src="https://github.com/user-attachments/assets/0cd056ff-cab0-4f60-868e-ac2c950173a1" />

Space outlaws stole your horse. Time to get him back.

Completed aspects include an item and bullet inventory system, beta rougelike level generator, several unique enemies, and shop.

Additionally, we have created an internal component system to facilitate asset creation (enemies, items, bullets, etc..).
